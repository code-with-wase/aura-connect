# Aura Connect

==================================================

UNIQUE & PREMIUM UI/UX REQUIREMENT

The most important requirement of this project is the UI/UX.

Do NOT create a generic messaging application.

Do NOT simply copy WhatsApp Web.

Do NOT reproduce WhatsApp's exact layout, colors, spacing, icons, or visual hierarchy.

Nexora must have its OWN completely original and recognizable visual identity.

The application should look like a real startup/product that could be launched commercially.

==================================================

DESIGN GOAL

Create a messaging experience that is:

Extremely professional

Modern

Unique

Premium

User-friendly

Minimal but visually rich

Intuitive

Fast to understand

Comfortable for long conversations

Visually memorable

Different from existing messaging applications

A user should immediately feel:

"This is not another WhatsApp clone."

The design should have a strong product identity.

==================================================

CHAT SCREEN — MOST IMPORTANT

The Chat Screen must be the visual centerpiece of Nexora.

Do not use a plain:

Sidebar + header + message list + input

layout without adding a unique design language.

Create a more sophisticated chat experience while keeping it simple.

The Chat Screen should include:

Elegant Chat Header

Show:

User avatar

Name

Online status

Last seen

Search

Audio call

Video call

More actions

But arrange these elements in a visually distinctive way.

Use subtle hierarchy and spacing.

Avoid overcrowding.

==================================================

MESSAGE DESIGN

Message bubbles should have an original visual style.

Do NOT simply copy WhatsApp message bubbles.

Use:

Modern rounded shapes

Subtle shadows

Carefully designed spacing

Different visual treatment for incoming/outgoing messages

Clean timestamps

Elegant read indicators

Small reaction badges

Reply previews

Smooth hover interactions

Messages should feel lightweight and premium.

Avoid giant bubbles.

Avoid excessive borders.

Avoid excessive shadows.

==================================================

MESSAGE INTERACTION

When hovering over a message:

Show a subtle floating action control.

Actions:

React

Reply

More

The interaction should feel smooth and modern.

Do not use old-fashioned browser-style context menus.

Create a polished custom interaction menu.

==================================================

CHAT BACKGROUND

Do NOT use a generic flat background.

Do NOT use a generated image.

Do NOT use a stock image.

Create a subtle CSS-based visual environment.

For example:

Very subtle geometric patterns

Soft gradients

Minimal abstract shapes

Low-opacity decorative elements

CSS noise-like effect if practical

Theme-aware background

The background must remain subtle.

Messages must always remain highly readable.

==================================================

MESSAGE INPUT — UNIQUE DESIGN

The message composer should be one of Nexora's signature UI elements.

Do not use a basic:

[ emoji ] [ input ] [ send ]

layout.

Create a refined floating composer.

Possible structure:

┌──────────────────────────────────────────────┐

│ + 😊 Write a message... 🎤 ➤ │

└──────────────────────────────────────────────┘

Use:

Floating rounded container

Soft border

Subtle shadow

Attachment button

Emoji button

Expanding textarea

Voice button

Send animation

Keyboard shortcut hint

The composer should feel modern and comfortable.

==================================================

SIDEBAR — UNIQUE DESIGN

Do not make the sidebar look like WhatsApp.

Create a distinctive sidebar.

Include:

Nexora branding

Profile

Search

Conversation filters

Chat list

New conversation button

Use strong visual hierarchy.

The active conversation should have a distinctive visual state.

Example:

Soft accent background

Small accent indicator

Subtle glow

Clear typography hierarchy

Do not overuse colors.

==================================================

NEW CHAT BUTTON

Create a visually memorable floating/action button.

It should be easy to discover.

On hover:

Smooth animation

Tooltip

Slight elevation

==================================================

PROFILE EXPERIENCE

Profile should not be a simple settings page.

Create a polished profile experience.

Use:

Large avatar/initials

Name

Username

About

Contact information

Use elegant cards and spacing.

==================================================

STATUS EXPERIENCE

Create a unique status interface.

Do not copy WhatsApp's exact status screen.

Use a modern story/status experience.

Possible layout:

Featured status

Recent updates

Viewed updates

Use circular progress indicators and clean cards.

==================================================

GROUP EXPERIENCE

Groups should have a distinctive visual identity.

Create:

Group avatar

Group information

Member list

Admin indicators

Group settings

Use modern cards and sections.

==================================================

EMPTY CHAT SCREEN

When no chat is selected, do NOT show a boring empty screen.

Create a beautiful Nexora welcome state.

Example concept:

Nexora logo/icon

"Your conversations, beautifully connected."

"Select a conversation or start a new one."

Include a subtle CSS animation or interactive visual element.

Do NOT use an image.

==================================================

COLOR SYSTEM

Create an original Nexora color system.

Do not use WhatsApp green as the primary brand color.

Recommended:

Primary:

Deep Indigo / Electric Violet

Secondary:

Soft Blue / Cyan

Background:

Neutral / Slate

Accent:

One carefully selected highlight color

Use CSS variables:

--primary

--primary-foreground

--background

--foreground

--surface

--surface-hover

--border

--muted

--accent

Ensure WCAG-friendly contrast.

==================================================

TYPOGRAPHY

Use a modern clean typography system.

Use strong hierarchy:

App title

Chat title

Message text

Metadata

Timestamps

Avoid overly decorative fonts.

The interface should remain highly readable.

==================================================

MICRO-INTERACTIONS

Add subtle micro-interactions throughout the application.

Examples:

Message appears with a very short animation

Send button responds on click

Reaction appears smoothly

Chat selection transitions smoothly

Sidebar items have subtle hover effects

Typing indicator animates

Online indicator gently pulses

Buttons have tactile hover/active states

Modal transitions smoothly

Animations should be:

Fast

Subtle

Professional

Do NOT make the application overly animated.

==================================================

USER FRIENDLINESS

Every interaction should be obvious.

A new user should understand the application without instructions.

Use:

Tooltips

Helpful empty states

Clear icons

Consistent buttons

Clear hover states

Keyboard support

Proper mobile navigation

Confirmation dialogs for destructive actions

Avoid hidden functionality.

==================================================

ACCESSIBILITY

Ensure:

Keyboard navigation

Visible focus states

ARIA labels

Proper semantic HTML

Accessible dialogs

Accessible dropdowns

Sufficient color contrast

Screen-reader-friendly buttons

==================================================

MOBILE EXPERIENCE

The mobile interface must NOT simply shrink the desktop UI.

Design a dedicated mobile experience.

Mobile:

Chat List

↓

Select Chat

↓

Full-screen Chat

↓

Back to Chat List

The message composer should adapt to mobile.

Header actions should collapse intelligently.

==================================================

DESKTOP EXPERIENCE

Desktop should take advantage of the larger screen.

Use:

Comfortable chat width

Spacious message area

Optional contextual information panel

Keyboard shortcuts

Hover interactions

Avoid unnecessarily stretching content across the entire screen.

==================================================

DARK MODE

Dark mode must feel intentionally designed.

Do NOT simply invert colors.

Create a dedicated dark theme.

Use:

Deep surfaces

Subtle borders

Carefully controlled accent colors

Proper text hierarchy

Reduced visual noise

==================================================

VISUAL CONSISTENCY

Every component must feel like it belongs to the same product.

Maintain consistent:

Border radius

Spacing

Typography

Icon sizes

Button sizes

Shadows

Colors

Animation speed

Create reusable design tokens.

==================================================

IMPORTANT FINAL DESIGN RULE

Before considering the UI complete, ask:

"Could a user mistake this for WhatsApp?"

The answer should be:

NO.

Nexora should be recognizable as its own product.

It should be:

Nexora first,

messaging application second,

WhatsApp-inspired functionality only where useful.

The final UI should look like a premium modern communication product designed by a professional product-design team, not like a copied messaging template.
